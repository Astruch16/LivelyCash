# Lively Cash ATMs

Marketing site for Lively Cash ATMs — an ATM placement and sales company
serving the Fraser Valley, British Columbia (Chilliwack, Abbotsford, Agassiz,
Hope and Harrison), deploying Hyosung Halo II hardware.

Built with Next.js 16 (App Router, Turbopack), React 19, TypeScript,
Tailwind CSS v4 and shadcn/ui.

## Getting started

```bash
npm install
cp .env.example .env.local   # then set NEXT_PUBLIC_SITE_URL
npm run dev
```

| Script                 | What it does               |
| ---------------------- | -------------------------- |
| `npm run dev`          | Dev server                 |
| `npm run build`        | Production build           |
| `npm start`            | Serve the production build |
| `npm run lint`         | ESLint                     |
| `npm run typecheck`    | `tsc --noEmit`             |
| `npm run format`       | Prettier write             |
| `npm run format:check` | Prettier check             |

## Structure

```
app/
  layout.tsx              Root layout: fonts, sitewide metadata, LocalBusiness JSON-LD,
                          skip link, header/footer
  page.tsx                Home
  about/ plans/ processing/ why-us/ contact/
  cities/[city]/          Five prerendered city pages (generateStaticParams)
  api/contact/route.ts    Contact form handler: honeypot → rate limit → zod → log
  sitemap.ts robots.ts opengraph-image.tsx not-found.tsx
  globals.css             Theme tokens (brand gold, light + dark surfaces), scroll reveal

components/
  ui/                     shadcn/ui primitives (regenerated by the shadcn CLI)
  marketing/              Site-specific composition
  json-ld.tsx

lib/
  site.ts                 Identity, nav, contact details
  cities.ts               Per-city SEO copy (hand-written, not templated)
  plans.ts                The three programs — figures are contractual
  faqs.ts                 FAQ content, also emitted as FAQPage JSON-LD
  seo.ts jsonld.ts        Metadata + structured-data builders
  contact-schema.ts       zod schema shared by client and server
  rate-limit.ts           RateLimitStore interface + in-memory implementation
```

## Notes

- **Theme.** The brand gold is `--accent` (`#DDC52B`). It is a fill colour: it
  only clears 1.7:1 on white, so it is used as a background with a near-black
  `--accent-foreground`, and as a text/icon colour only on the dark surfaces.
  Dark sections opt in with `<Section tone="dark">`, which applies the `.dark`
  class so every semantic token flips and contrast resolves automatically.
- **Client components.** Only three: the partner carousel, the header
  (dropdown + mobile sheet), and the contact form. Scroll reveal is CSS-only
  (`animation-timeline: view()`, behind `@supports` and a reduced-motion guard).
- **Rendering.** Every page is statically generated; only the contact API route
  is dynamic.
